# NavOils - Groundnut Oil Landing Page

## Oasis Infobyte Web Development Internship

### Task Number

Task 1

### Objective

To design and develop a responsive landing page for NavOils, a premium groundnut oil brand, using HTML and CSS.

### Project Description

NavOils is a product-focused landing page created to showcase the quality, benefits, and versatility of cold-pressed groundnut oil. The website includes product highlights, brand information, customer-focused sections, and a modern responsive design.

### Features

* Responsive landing page design
* Hero section
* Product showcase
* Benefits section
* Call-to-action sections
* Footer with contact information

### Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* GitHub

### Outcome

Successfully developed a visually appealing and responsive landing page that demonstrates fundamental web development and UI design skills.
